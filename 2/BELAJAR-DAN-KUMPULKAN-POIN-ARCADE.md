# ⭐ Prioritaskan Arcade Games Terlebih Dahulu

Ini adalah salah satu tips paling penting yang sering disampaikan oleh fasilitator.

**Kerjakan Arcade Games terlebih dahulu sebelum mengerjakan Skill Badge lainnya.**

Mengapa?

Karena kuota peserta pada setiap Arcade Game umumnya **terbatas**.

Jika kuota sudah habis, kamu mungkin harus menunggu hingga tersedia kembali atau bahkan kehilangan kesempatan mengikuti game tersebut pada periode tertentu.

Dengan mengerjakan Arcade Games lebih awal, kamu memiliki peluang lebih besar untuk:

- Menyelesaikan seluruh milestone.
- Mengumpulkan lebih banyak poin.
- Menghindari kehabisan kuota.
- Menyelesaikan target sebelum deadline.

Strategi sederhana ini dapat memberikan keuntungan besar selama mengikuti program.

# 🏆 Apa Itu Arcade Points?

Arcade Points merupakan sistem poin resmi yang diberikan kepada peserta setelah berhasil menyelesaikan berbagai aktivitas dalam Google Skills Arcade.

Poin ini menjadi salah satu elemen utama dalam program karena akan menentukan hadiah yang dapat kamu peroleh di akhir periode.

Poin diperoleh dari berbagai aktivitas, antara lain:

- Menyelesaikan Arcade Games.
- Menyelesaikan Skill Badge.
- Menyelesaikan Milestone.
- Menyelesaikan Bonus Milestone.
- Menyelesaikan program GEAR.
- Mengikuti challenge tertentu yang diumumkan oleh Google.

Semakin aktif kamu belajar, semakin besar jumlah poin yang berhasil dikumpulkan.

# 🚀 Bersiap Mengikuti Program GEAR

GEAR (Gemini Enterprise Agent Ready) merupakan program wajib yang harus diikuti oleh seluruh peserta.

Mengapa?

Karena penyelesaian GEAR menjadi salah satu syarat untuk memperoleh Bonus Points pada beberapa milestone.

Jangan menunda pendaftaran.

Segera daftar dan selesaikan badge GEAR agar tidak kehilangan kesempatan memperoleh poin tambahan.

# 🌟 Bonus Milestone
